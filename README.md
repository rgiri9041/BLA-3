# AWS Educational Presentation for Generative AI Development Certification 

A collection of three comprehensive presentations, designed for educational videos and study material for the AWS Certified Generative AI Developer certification.

Each presentation includes detailed slide content notes in simple English, with practical examples. They are ideal for beginners and anyone preparing for AWS certifications.

## Overview

This repository contains three in-depth presentations covering foundational AWS topics for Generative AI development:

1. **LLM Agents** – How agents work with Amazon Bedrock, tools, memory, planning, and safety.
2. **Amazon S3 Storage Classes** – Storage classes, lifecycle rules, replication, encryption, and access logging.
3. **Amazon DynamoDB** – NoSQL database concepts, primary keys, indexes, and vector search for AI.

Each presentation is structured as slides with bullet points and accompanying speaker notes, making them suitable for recording educational videos or self-study. The content is based on the **AWS Certified Generative AI Developer** course material.


### LLM Agents

**Description:**

**Description:**  
An introduction to LLM Agents, covering core components like memory, planning, and tools. Explains how agents differ from basic LLMs, how they use Amazon Bedrock Action Groups, Knowledge Bases, and Code Interpreter, and how to deploy them safely.

**Key Topics:**
- Core components: LLM, memory, planning, tools, prompts
- Amazon Bedrock Action Groups and Lambda integration
- Knowledge Bases and Agentic RAG
- Code Interpreter
- Safety, limitations, and deployment best practices
- Practical example: Building a weather assistant

### Amazon S3 Storage Classes

**Description:**  
A comprehensive guide to Amazon S3 storage classes, lifecycle rules, replication, encryption options, and access logging. Includes practical examples and comparisons of encryption methods.

**Key Topics:**
- S3 storage classes: Standard, Intelligent-Tiering, Standard-IA, One Zone-IA, Glacier classes
- Lifecycle rules: transitions and expiration
- Storage Class Analysis
- Replication: SRR and CRR
- Encryption: SSE-S3, SSE-KMS, DSSE-KMS, SSE-C, client-side encryption
- AWS KMS limitations and quotas
- S3 Server Access Logging
- Practical example: Managing company S3 data

### Amazon DynamoDB

**Description:**  
An introduction to Amazon DynamoDB, covering NoSQL concepts, primary keys, operations, capacity modes, indexes, and advanced features. Explains how DynamoDB supports Generative AI applications, including vector search.

**Key Topics:**
- Tables, items, attributes
- Primary keys: partition and sort keys
- Read/write operations: PutItem, GetItem, UpdateItem, DeleteItem, Query, Scan
- Capacity modes: on-demand and provisioned
- Secondary indexes: GSI and LSI
- Features: Streams, TTL, Global Tables, PITR, encryption
- DynamoDB for Generative AI: agent memory, conversation history
- Vector indexes and similarity search (SearchVectors API)
- Key takeaways for DynamoDB design
